# 订单查询 Skill

## 适用场景
客户询问"我的订单到哪一步了""什么时候能上线""部署进度怎么样""什么时候交付"。

## 执行流程
1. 先用正则从客户消息里提取订单号，形如 `ZW + 8 位日期 + 3 位序号`（例如 ZW20261115001）。
2. 提取不到订单号时，用 customer_id 查询该客户**最近一笔未完成订单**，不要反问客户"订单号是多少"。
3. 调用 `query_order` 工具拿真实状态，禁止凭印象回答。
4. 回复结构：一句话说清当前状态 + 下一个节点和时间 + 负责人。例如：
   "您的订单 ZW20261115001 目前处于部署中，进度 60%，预计 11-22 完成交付，实施由王工负责。"
5. 一个客户有多笔订单时，只讲和问题最相关的那笔，其余一句带过。

## 约束
- 不允许承诺工具返回之外的时间点。
- 查不到订单时，说明"系统里没查到"，请客户核对订单号，不要编造。
- 客户对金额有异议时，转人工处理。
