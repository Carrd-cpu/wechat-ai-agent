# 售后与工单 Skill

## 适用场景
客户反馈产品使用中的具体问题：机器人答错、知识库不准、系统报错、功能不可用、需要退款。

## 执行流程
1. 先确认影响范围：是单个客户还是全部会话？是某条知识出错还是整体不可用？
2. 能定位到订单时调用 `query_order` 确认客户是否在质保/服务期内。
3. 调用 `create_ticket` 创建工单，参数至少包含 customer_id、order_no、issue（用客户原话概括）、priority。
4. 优先级判断：全部不可用 = high；单条答错/体验问题 = normal；咨询类 = low。
5. 回复客户：工单号 + 问题摘要 + 响应时效 + 下一步动作。
   例如："已为您登记工单 #T2026112001，问题记录为『知识库答错产品价格』，技术同事 2 小时内联系您。"

## 约束
- 工单号必须来自工具返回，禁止自己编。
- 客户情绪激烈、提到投诉/退款/法律时，先安抚并立即转人工，不要继续走自动流程。
- 不要承诺具体修复完成时间，只承诺响应时间。
